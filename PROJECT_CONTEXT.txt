1. PROJECT PURPOSE
Photo Group Portal is a full-stack, AI-powered platform for photographers to host event 
media. Photographers create room-isolated collections and upload bulk photos. Face detection 
and vector embeddings process photos asynchronously. Event attendees scan a room QR code, 
initiate a WhatsApp selfie workflow, and receive a secure, expiring gallery link containing 
only their matched photographs.

6. DATABASE SCHEMA SUMMARY
- `user`: `id` (UUID/PK), `email` (VARCHAR, Unique, Indexed), `password_hash` (VARCHAR), `role` (VARCHAR, Indexed), `is_active` (BOOLEAN), `created_at` (TIMESTAMPTZ), `updated_at` (TIMESTAMPTZ)
- `system_log`: `id` (INTEGER/PK), `level` (VARCHAR, Indexed), `module` (VARCHAR), `message` (TEXT), `details` (JSONB/TEXT), `created_at` (TIMESTAMPTZ), `updated_at` (TIMESTAMPTZ)

7. CURRENT API ENDPOINTS
- `GET /` — API root landing
- `GET /api/health` — Basic service liveness check
- `GET /api/health/db` — PostgreSQL connectivity check
- `GET /api/health/system` — System environment status
- `GET /api/v1/health` — Detailed diagnostic metrics and database event counter

- `LOG_LEVEL` (string) — "INFO" | "DEBUG" | "WARNING" | "ERROR"
- `API_V1_STR` (string) — "/api/v1"

- `CORS_ORIGINS` (list[string]) — Allowed frontend domains
- `VITE_API_URL` (string) — Base backend endpoint for Vite frontend
- `STORAGE_DIR` (string) — Base storage directory path (`./storage`)

9. CORE FUNCTIONS & ARCHITECTURAL RESPONSIBILITIES
- `validate_config()`: Validates critical environment parameters upon application load.
- `setup_logging()`: Configures standard stream handlers and rotating file handlers (`logs/app.log`).
- `app_exception_handler()`: Intercepts unhandled exceptions and formats output into standard response contract: `{"error": {"code": "...", "message": "..."}}`.
- `log_requests()`: ASGI middleware calculating and logging request execution duration.

10. VERIFICATION & COMMAND REFERENCE
- Activate Environment (Windows): `.\venv\Scripts\Activate.ps1`
- Activate Environment (POSIX): `source venv/bin/activate`
- Run Backend: `python -m uvicorn backend.app.main:app --reload --port 8000`
- Apply Migrations: `python -m alembic upgrade head`
- Execute Tests: `python -m pytest tests/ -v`
- Run Frontend Dev Server: `cd frontend && npm run dev`
